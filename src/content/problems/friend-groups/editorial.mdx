## Idea

Build the graph as an **adjacency list**: `adj[v]` holds the friends of `v`.
Each friendship is added in both directions.

A friend group is a **connected component**. Go through the students in order;
whenever one hasn't been seen, it starts a new group. Explore the whole group
with an **iterative DFS** (a list used as a stack), counting its members:

```python
stack = [start]
seen[start] = True
while stack:
    v = stack.pop()
    for w in adj[v]:
        if not seen[w]:
            seen[w] = True
            stack.append(w)
```

A recursive DFS would also be correct, but one long chain of `2·10^5` students
means `2·10^5` nested calls — far beyond Python's default recursion limit.
The stack version has no depth limit.

Duplicate friendships just add a repeated neighbour; the `seen` check ignores it.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n, m = int(data[0]), int(data[1])
    adj = [[] for _ in range(n + 1)]
    for i in range(m):
        a, b = int(data[2 + 2 * i]), int(data[3 + 2 * i])
        adj[a].append(b)
        adj[b].append(a)
    seen = [False] * (n + 1)
    groups = 0
    largest = 0
    for start in range(1, n + 1):
        if seen[start]:
            continue
        groups += 1
        size = 0
        seen[start] = True
        stack = [start]
        while stack:
            v = stack.pop()
            size += 1
            for w in adj[v]:
                if not seen[w]:
                    seen[w] = True
                    stack.append(w)
        largest = max(largest, size)
    print(groups, largest)

main()
```

**Complexity:** <Complexity time="O(N + M)" space="O(N + M)" />
