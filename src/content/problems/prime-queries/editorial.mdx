## Idea

Checking each query separately by trial division costs about `x · sqrt(x)`
steps per query — far too slow. Instead, do the work **once**:

1. **Sieve of Eratosthenes** up to the largest query `M`: start with every
   number marked prime, and for each prime `i` (up to `sqrt(M)`) cross out
   `i·i, i·i + i, …`. Python's slice assignment crosses out a whole row in one
   fast step.
2. **Prefix count:** `count[x]` = number of primes ≤ `x`. `itertools.accumulate`
   adds up the 0/1 marks.
3. Each query is now a single lookup.

```python
import sys
from itertools import accumulate
from math import isqrt

def main():
    data = sys.stdin.buffer.read().split()
    q = int(data[0])
    xs = list(map(int, data[1:1 + q]))
    m = max(xs)
    is_prime = bytearray([1]) * (m + 1)
    is_prime[0] = 0
    if m >= 1:
        is_prime[1] = 0
    for i in range(2, isqrt(m) + 1):
        if is_prime[i]:
            is_prime[i * i :: i] = bytes(len(range(i * i, m + 1, i)))
    count = list(accumulate(is_prime))
    print("\n".join(str(count[x]) for x in xs))

main()
```

`bytearray` uses one byte per number, so the sieve for `10^6` takes about 1 MB.

**Complexity:** <Complexity time="O(M log log M + Q)" space="O(M)" /> where M is the largest query.
