## Why this matters

Inputs in contests have many values — `N` numbers, `Q` queries, `T` test
cases. Loops let you handle all of them with a few lines. Knowing how many
times a loop runs also tells you whether your solution will finish in time.

<KeyIdea>
Python does roughly **10 million simple steps per second** (often less in the
browser). Multiply your loop sizes and compare with that before you code.
</KeyIdea>

## for and range

`range(n)` gives `0, 1, …, n-1`. `range(a, b)` stops **before** `b`, and
`range(a, b, step)` jumps by `step`.

```python
for i in range(5):          # 0 1 2 3 4
    print(i)

for i in range(1, 11, 3):   # 1 4 7 10
    print(i)

for i in range(10, 0, -1):  # 10 9 … 1
    print(i)
```

## Looping over data

Loop directly over a list (or string) — no index needed:

<RunnableExample title="Count and total" stdin={"5\n3 8 -2 7 4\n"}>

```python
n = int(input())
nums = list(map(int, input().split()))
total = 0
positives = 0
for x in nums:
    total += x
    if x > 0:
        positives += 1
print(total, positives)
```

</RunnableExample>

Need the index too? Use `enumerate`:

```python norun
for i, x in enumerate(nums):
    print(i, x)
```

## Test cases

Many problems start with `T`, the number of test cases. Solve each one inside
a loop:

<RunnableExample title="T test cases" stdin={"3\n1 2\n10 20\n-5 5\n"}>

```python
t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    print(a + b)
```

</RunnableExample>

`_` is a normal variable name that says "I don't use this value".

## while, break and continue

`while` repeats as long as its condition is true — useful when you don't know
the number of steps in advance:

```python
n = 12345
digits = 0
while n > 0:
    n //= 10
    digits += 1
print(digits)   # 5
```

- `break` leaves the loop immediately.
- `continue` skips to the next round.

```python norun
for x in nums:
    if x < 0:
        continue      # ignore negatives
    if x == 0:
        break         # stop at the first zero
    print(x)
```

## How long does a loop take?

| Constraint on N | Loops you can afford |
| --- | --- |
| N ≤ 10^6 | one loop over N <Complexity time="O(N)" /> |
| N ≤ 5000 | two nested loops <Complexity time="O(N^2)" /> (careful in Python) |
| N ≤ 500 | three nested loops <Complexity time="O(N^3)" /> is borderline |

Two nested loops over `N = 10^5` items is `10^10` steps — far too slow.

## Common mistakes

- Off-by-one: `range(1, n)` stops at `n-1`. To include `n` write `range(1, n + 1)`.
- Resetting the total **inside** the loop instead of before it.
- `while` loops that never change their condition — they run forever (the IDE stops them at the time limit).
- Changing a list while looping over it — loop over a copy or build a new list.

## Competition use

- Read all values first, then loop.
- Before writing nested loops, check `N` in the constraints and estimate the steps.
- With many output lines, collect them in a list and print `"\n".join(out)` once — it is faster than many `print` calls.

## Exercises

<Exercise title="Count multiples">
Read `N` and `K`, then `N` integers. Print how many of them are divisible by `K`.

<Answer>

```python
n, k = map(int, input().split())
nums = list(map(int, input().split()))
count = 0
for x in nums:
    if x % k == 0:
        count += 1
print(count)
```

</Answer>
</Exercise>

<Exercise title="Factorial">
Read `N` (`0 ≤ N ≤ 100`) and print `N!` (the product `1 · 2 · … · N`; `0! = 1`).

<Answer>

```python
n = int(input())
result = 1
for i in range(2, n + 1):
    result *= i
print(result)
```

</Answer>
</Exercise>

<Exercise title="Digit sum">
Read a non-negative integer and print the sum of its digits using a `while` loop.

<Answer>

```python
n = int(input())
total = 0
while n > 0:
    total += n % 10
    n //= 10
print(total)
```

</Answer>
</Exercise>

<Exercise title="Multiplication table">
Read `N` and print the `N × N` multiplication table: row `i` contains
`i·1 i·2 … i·N` separated by spaces.

<Answer>

```python
n = int(input())
for i in range(1, n + 1):
    print(*[i * j for j in range(1, n + 1)])
```

</Answer>
</Exercise>
