## Why this matters

In a contest, your program never talks to a person. A judge feeds it text on
**standard input (stdin)** and compares what you print on **standard output
(stdout)** character by character. Most beginner "wrong answers" are really
input/output mistakes.

<KeyIdea>
The judge only reads what you print. Print **exactly** the answer in the
required format — no prompts, no labels, no extra spaces or lines.
</KeyIdea>

## Reading input

`input()` reads **one line** as a string, without the newline.

```python
name = input()          # "Ana"
n = int(input())        # "5"  -> 5
```

Several numbers on one line: `split()` cuts the line at spaces, `map(int, ...)`
converts every piece.

<RunnableExample title="Two numbers on one line" stdin="3 4">

```python
a, b = map(int, input().split())
print(a + b)
```

</RunnableExample>

Many lines, when the first line says how many follow:

```python
n = int(input())
for _ in range(n):
    x = int(input())
```

For large inputs, `sys.stdin` is much faster. It reads **everything** at once
and `split()` turns it into a list of words, no matter how the lines are broken.
Reading all input this way costs <Complexity time="O(input size)" />.

<RunnableExample title="Read all input at once" stdin={"3\n10 20 30\n"}>

```python
import sys
data = sys.stdin.read().split()
n = int(data[0])
nums = list(map(int, data[1:1 + n]))
print(sum(nums))
```

</RunnableExample>

## Printing output

```python
print(a + b)                 # 7
print(a, b)                  # "3 4"   (space-separated)
print(*nums)                 # "1 2 3" (unpack a list)
print(f"{3.14159:.2f}")      # "3.14"  (fixed decimals)
print("\n".join(map(str, nums)))  # one per line, fast
```

## Common mistakes

- Printing extra text like `print("Answer:", x)` — the judge only wants `x`.
- Writing `input("Enter N: ")` — the prompt is printed to stdout and causes Wrong Answer.
- Forgetting `int(...)`, so `"3" + "4"` becomes `"34"`.
- Calling `input()` once when the numbers are on **separate lines**.
- Wrong number of decimals: read the output spec carefully.

## Competition use

Start every solution by writing the input-reading code **first**, then print
the parsed values to check them against the sample input before solving.

## Exercises

<Exercise title="Sum of two">
Read two integers on one line and print their sum.

<Answer>

```python
a, b = map(int, input().split())
print(a + b)
```

</Answer>
</Exercise>

<Exercise title="Largest number">
Read `N`, then `N` integers on the next line, and print the largest.

<Answer>

```python
n = int(input())
nums = list(map(int, input().split()))
print(max(nums))
```

</Answer>
</Exercise>

<Exercise title="Greeting">
Read a name and print `Hello, <name>!` — for input `Ana` print `Hello, Ana!`.

<Answer>

```python
name = input()
print(f"Hello, {name}!")
```

</Answer>
</Exercise>
