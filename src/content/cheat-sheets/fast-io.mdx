| Task | Code | Notes |
| --- | --- | --- |
| One int | `n = int(input())` | |
| Ints on a line | `a = list(map(int, input().split()))` | |
| Everything at once | `data = sys.stdin.buffer.read().split()` | fastest; items are bytes, `int()` still works |
| Fast line reader | `input = sys.stdin.readline` | keeps the `\n` — use `.strip()` for strings |
| Print a list | `print(*a)` | space-separated |
| Many lines out | `sys.stdout.write("\n".join(map(str, out)) + "\n")` | avoid printing in a loop |

```python
import sys

def main() -> None:
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))
    print(sum(a))

main()
```
