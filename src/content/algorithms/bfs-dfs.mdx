## Why this matters

Roads between towns, friendships, mazes, pixels of the same colour — many
problems are really **graphs**: things (nodes) joined by connections (edges).
Two searches answer most beginner graph questions: **BFS** for "fewest steps"
and **DFS** for "what is connected to what".

<KeyIdea>
BFS uses a **queue** and visits nodes in order of distance, so it finds
shortest paths when every step costs the same. DFS uses a **stack** and goes
deep first. Both visit each node and edge once:
<Complexity time="O(V + E)" />.
</KeyIdea>

## Storing a graph

Nodes are usually numbered `1 … N`. An **adjacency list** keeps, for each
node, the list of its neighbours:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]
for _ in range(m):
    a, b = map(int, input().split())
    adj[a].append(b)
    adj[b].append(a)      # leave this out for one-way (directed) edges
```

It uses `O(N + M)` memory. A grid needs no list at all: the neighbours of
`(r, c)` are the four cells around it.

## BFS: shortest paths

<RunnableExample title="Distances from node 1" stdin={"6 6\n1 2\n1 3\n2 4\n3 4\n4 5\n2 5\n"}>

```python
from collections import deque

n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]
for _ in range(m):
    a, b = map(int, input().split())
    adj[a].append(b)
    adj[b].append(a)

dist = [-1] * (n + 1)      # -1 = not reached
dist[1] = 0
queue = deque([1])
while queue:
    v = queue.popleft()
    for w in adj[v]:
        if dist[w] == -1:
            dist[w] = dist[v] + 1
            queue.append(w)
print(dist[1:])            # node 6 has no edges: -1
```

</RunnableExample>

Use `deque.popleft()` — `list.pop(0)` is `O(N)` per call and turns BFS into
`O(N^2)`. Set `dist` when a node is **added** to the queue, so it is added only once.

## BFS on a grid

```python
from collections import deque

def grid_bfs(grid, sr, sc):
    rows, cols = len(grid), len(grid[0])
    dist = [[-1] * cols for _ in range(rows)]
    dist[sr][sc] = 0
    queue = deque([(sr, sc)])
    while queue:
        r, c = queue.popleft()
        for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
            if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] != "#" and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                queue.append((nr, nc))
    return dist
```

Always check the bounds **before** reading `grid[nr][nc]` — in Python
`grid[-1]` silently means "last row".

## DFS: exploring everything reachable

DFS goes as deep as possible before backing up. The recursive version is
short, but recursion depth can reach `N` — about 1000 by default in Python.
Use your own stack instead:

```python
def reachable(start, adj, seen):
    seen[start] = True
    stack = [start]
    size = 0
    while stack:
        v = stack.pop()
        size += 1
        for w in adj[v]:
            if not seen[w]:
                seen[w] = True
                stack.append(w)
    return size
```

## Connected components

Start a search from every node not seen yet. Each new start is a new component:

```python
seen = [False] * (n + 1)
components = 0
for v in range(1, n + 1):
    if not seen[v]:
        components += 1
        reachable(v, adj, seen)
print(components)
```

BFS works just as well here; for counting, the order doesn't matter.

## Common mistakes

- Marking nodes visited when they are popped instead of when they are pushed — the same node enters the queue many times.
- `list.pop(0)` as a queue — use `collections.deque`.
- Recursive DFS on `10^5` nodes → `RecursionError`.
- Forgetting the reverse edge in an undirected graph.
- Using BFS for shortest paths when edges have **different** weights (that needs Dijkstra — a later topic).

## Competition use

- "Fewest moves / steps / transfers" with equal costs → BFS.
- "How many groups / islands / regions", "is X connected to Y" → DFS or BFS.
- Read the graph with `sys.stdin.buffer.read().split()` when `M` is large.

## Exercises

<Exercise title="Count islands">
Read `R` and `C`, then a grid of `#` (land) and `.` (water). Islands are groups
of land cells joined up, down, left or right. Print the number of islands.

<Answer>

```python
r, c = map(int, input().split())
grid = [input().strip() for _ in range(r)]
seen = [[False] * c for _ in range(r)]
islands = 0
for i in range(r):
    for j in range(c):
        if grid[i][j] == "#" and not seen[i][j]:
            islands += 1
            seen[i][j] = True
            stack = [(i, j)]
            while stack:
                y, x = stack.pop()
                for ny, nx in ((y + 1, x), (y - 1, x), (y, x + 1), (y, x - 1)):
                    if 0 <= ny < r and 0 <= nx < c and grid[ny][nx] == "#" and not seen[ny][nx]:
                        seen[ny][nx] = True
                        stack.append((ny, nx))
print(islands)
```

</Answer>
</Exercise>

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]
for _ in range(m):
    a, b = map(int, input().split())

    adj[b].append(a)

queue = deque([1])

print(dist[n])
```

<Exercise title="Two teams">
Read `N` and `M`, then `M` pairs of students who are rivals. Can the students be
split into two teams so that no rivals are on the same team? Print `YES` or `NO`.

<Answer>

Colour each component with BFS, alternating 0 and 1. A rival pair with the same
colour means it's impossible.

```python
from collections import deque
n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]
for _ in range(m):
    a, b = map(int, input().split())
    adj[a].append(b)
    adj[b].append(a)
color = [-1] * (n + 1)
ok = True
for s in range(1, n + 1):
    if color[s] != -1:
        continue
    color[s] = 0
    queue = deque([s])
    while queue and ok:
        v = queue.popleft()
        for w in adj[v]:
            if color[w] == -1:
                color[w] = 1 - color[v]
                queue.append(w)
            elif color[w] == color[v]:
                ok = False
print("YES" if ok else "NO")
```

</Answer>
</Exercise>
